# Veya Website Product Facts

## Product positioning

Veya 是 AI-native Teaching & Learning OS，以 governed Learning Harness、Learning Evidence、Learner Model、Teaching Policy 和 Teacher Control Plane 连接学生学习与教师教学。

## Student shipped capabilities represented on the site

Today / Next Step, Courses, Tasks, Learning Session, Ask Veya, Challenge / Discover, Learning Map, Learning Evidence.

## Teacher shipped capabilities represented on the site

Command Center, Student Insight, Learner Model, Evidence Review, Intervention, Teaching Policy, Content Studio, Task Workspace, Class Management, Pilot Results.

## Competitive differentiation

Evidence-first, teacher-in-control, closed-loop learning, shared student/teacher context, governed Harness, provider-neutral architecture.

Roadmap 能力不得写成当前已发布功能；未经授权的学校、教师、客户评价不得伪造。
